Why it exists
We already
figured this out.
That’s the problem this project starts with. A new AI session can find your code and still miss the conversation that explains it.
01
Stop rebuilding context from scratch.
Preserve the constraint, the rejected alternative, and the reason a choice was made. Start the next task with the decisions that matter.
02
Spend context on the task ahead.
Retrieve a small, relevant packet and expand the evidence when needed. The aim is fewer repeated explanations and searches; token savings still need to be measured.
03
Change agents without losing the thread.
Project memory belongs to the project. Supported host adapters would carry confirmed reasoning from one coding environment into the next.


Under the hood
Three foundations.
One useful answer.
“What matters here, why was it decided, and does it still apply to this version?”
FIND THE MATERIAL
zvec-grep
Reuse the project index to discover relevant code and text. Connect those locations to the decisions behind them.
REMEMBER THE REASON
SQLite
Store retained conversations, decision revisions, and source links locally. Search by scope, file, or the words in the rationale.
CHECK THE VERSION
Git + content anchors
Keep the original source version attached. Changed code yields historical evidence until its current location is verified.
